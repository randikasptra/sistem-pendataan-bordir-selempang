# Sistem Distribusi PO Bordir

Aplikasi internal untuk menyalurkan Purchase Order (PO) dari pihak internal kepada beberapa vendor bordir. 

## Referensi Dokumentasi
- Kebutuhan produk dan aturan bisnis: [PRD.md](./PRD.md)
- Status pengembangan dan progres: [docs/PROGRESS.md](./docs/PROGRESS.md)
- Keputusan teknis penting: [docs/DECISIONS.md](./docs/DECISIONS.md)

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL, Auth, Storage, RLS)
- Fabric.js (Canvas Image Editor)
- Zod (Validation)
- PWA

Proyek ini dibangun berdasarkan kebutuhan dari `PRD.md` dan dikembangkan menggunakan proses dokumentasi bertahap.
